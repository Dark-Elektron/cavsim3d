# Quick run

One notebook that takes a model exported from CST Studio Suite, as a STEP file with its
ports, all the way to results: S- and Z-parameters, resonances with their loaded and
external Q, and the figures of merit of the trapped modes, with plots.

It runs as it is on an example, a two-cavity module of the C3794 cavity with its couplers.
To get the same results for your own model, export it from CST as a STEP file, change the
settings at the top of the notebook, and run all cells.

1. [Results from a CST model](quick_run.ipynb)

The notebook moves fast and explains little. The [Basics](../basics/index.md) tutorials take
the same steps one at a time, on a waveguide whose answer is known.
